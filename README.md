# Code Reasoning Teacher

**从看懂代码，到自己写出来。**

这是一个面向编程学习者的 Codex Skill。它引导 Codex 从需求出发，重建程序设计思路，追踪实际执行过程，并解释函数、语法和算法为什么这样使用。目标是帮助学习者独立复现，而不只是在当下看懂答案。

[查看介绍页面](https://forwindreach.github.io/code-reasoning-teacher/) · [阅读 SKILL.md](skills/code-reasoning-teacher/SKILL.md)

## 适合谁

- **编程初学者：** 想弄清变量、条件、循环、函数、输入输出如何组合成一个完整程序。
- **蓝桥杯和算法竞赛学习者：** 想从暴力思路推到更高效的算法，理解边界、复杂度和可迁移的方法。
- **技术面试求职者：** 想解释“为什么这样设计”，而不是只背一份题解或模板。

## 它会怎样讲解

1. 把题目翻译成输入、输出、约束和需要维护的数据。
2. 从零开始重建合理的编写思路，说明每一步的目的与顺序。
3. 用具体输入追踪分支、变量变化和最终输出。
4. 拆解函数与语法的写法、参数、返回值、异常，以及在当前代码中使用的原因。
5. 收束为可以自己重新写出的步骤。

遇到格式、语法或逻辑问题时，它会区分代码实际行为与可能的设计意图，不把猜测当成事实。

## 安装到 Codex

下载本仓库后，把 [`skills/code-reasoning-teacher`](skills/code-reasoning-teacher) **整个文件夹**放进你的 Codex skills 目录。在 Mac 上，可以通过访达打开个人文件夹，显示隐藏文件夹，再依次进入 `.codex`、`skills`。安装后的结构应为：

```text
~/.codex/skills/
└── code-reasoning-teacher/
    └── SKILL.md
```

Codex 可以根据问题自动选择这个 Skill。想指定它时，在提问中写 `$code-reasoning-teacher`。如果新安装的 Skill 没出现，重启 Codex。

## 试着这样提问

**入门代码**

> 使用 $code-reasoning-teacher。请先讲如果从零开始写，我会怎样设计这段程序，再解释每个函数和语法为什么在这里使用：［粘贴代码］

**蓝桥杯 / 算法竞赛**

> 请从最直接的做法开始，带我推导这道题的解法。用具体数据走一遍，解释边界与复杂度，最后让我能独立重写：［粘贴题目或代码］

**技术面试**

> 请像面试官追问一样，解释这段代码的设计选择、关键不变量和边界情况；先让我理解，再给我一个可以自己复述的思路：［粘贴代码］
